# Dreamina/Seedream 4.0 架构 → A 股面板：2 MB 预实验

> 2026-11-12。把即梦/Dreamina 4.0（图像侧对应 Seedream 4.0）的"高压缩 VAE + 扩散 Transformer"架构搬到 A 股日线面板上，训练一个约 2 MB 参数的小模型，再用它做 2024–2026 的模拟回测。
>
> 模拟盘，仅供策略研究，不构成投资建议。

## 0. 结论

- **2 MB 完全训得动。** 526,115 个参数（fp32 2.01 MiB，fp16 1.00 MiB）；训练提交到 lab 的 Slurm `gpu` 队列（RTX 5090，`dreamina.sbatch`），本地 M4 MPS 只做冒烟（15 轮约 61 秒）。数据量（653 股 × 2,759 日 × 25 特征，42.6 万训练样本）足以支撑这个量级，按"每参数约 86 个原始数值 / 1.2 个样本窗口"算，2 MB 已经是当前数据的上限附近，再大主要是在拟合噪声。
- **架构能跑通，但 2 MB 的生成式预训练没有稳定打赢"直接读上下文"的对照。** 做了两种 tokenization（16 股/patch = 2.01 MB；8 股/patch = 1.87 MB）：
  - 16 股/patch：生成 + 上下文 测试 IC **0.0423**，只用上下文 **0.0539**；
  - 8 股/patch：生成 + 上下文 测试 IC **0.0443**，只用上下文 **0.0366**；
  - 只喂生成结果（不带上下文）：测试 IC **0.0053**，基本没有信号；
  - v2 的 GRU+注意力参考：测试 IC **0.0636**。
  - 两个 tokenization 下"生成 vs 不生成"的符号相反，差距（±0.01–0.02 IC）与 probe 种子/区间的噪声同量级；**目前不能声称生成式预训练带来了可靠增量**。
- **结论与《Share 下一轮方案》一致**：当前瓶颈是数据/特征/信噪比，不是参数容量。把图像/视频生成架构"暴改"成股票模型在工程上可行，但在这个数据规模下继续堆参数/堆生成步数，预期只降低训练损失、不提高样本外 IC；下一轮应优先扩数据、扩特征、做严格验证。
- **一个重要旁证**：把"真实未来 5 日特征"喂给同一个 probe，测试 IC 0.9697、回测 +15,601%。这说明整条"面板 → 视频 → 排序 → 组合"的管线是通的，瓶颈在"预测未来"这一步，不在回测/执行环节。这个数字是泄漏上界，**不能当作策略结果**。

## 1. 把图/视频改成股票数据

即梦/Dreamina 4.0 的图像模型是 Seedream 4.0（[arXiv:2509.20427](https://arxiv.org/abs/2509.20427)）：高效扩散 Transformer（DiT）+ 高压缩 VAE（大幅减少图像 token 数）、VLM 做提示词编码、统一文生图/编辑、flow matching 与少步采样。下表的映射把"图像/视频"逐项换成股票面板：

| Seedream 4.0 | 本实验 | 说明 |
| --- | --- | --- |
| 一张图 `H × W × C` | 一个交易日的截面 `653 股 × 26 通道` | 25 个日线因子 + 1 个有效股票掩码 |
| 一段视频 `T × H × W × C` | 20 日上下文 + 未来 5 日 | 未来 5 日是要生成的"视频" |
| `16 × 16` 图像 patch | 16 只连续股票 × 26 通道 = 416 维 | 固定股票顺序，最后一组补齐 |
| 高压缩 VAE | StockVAE：416 → 96 维 latent | 4.3× 压缩，8.2 万参数 |
| DiT block | 3 个 block，d=96，6 头，self-attn + cross-attn + MLP | 205 个未来 token |
| adaLN 时间步条件 | 共享 6 路调制，输入 = 时间步 + 市场 regime | 5.6 万参数 |
| VLM 文本提示词 | 8 维 regime 向量（指数 1/5/20/60 日收益、20/60 日波动、广度、离散度）+ 82 个上下文 token | "市场状态"代替"文字 prompt" |
| flow matching / 少步采样 | rectified flow，6 步 Euler 采样 | 生成 5 日未来 |
| 原生高分辨率 | 全截面 653 只、5 个未来交易日 | 不降采样股票池 |

一句话：**把"日截面"当图像、"日截面序列"当视频、"市场状态"当提示词，VAE 压缩股票 patch，DiT 在 latent 上做条件生成。**

## 2. 参数预算：为什么是 2 MB

| 量 | 数值 |
| --- | ---: |
| 面板 | 653 股 × 2,759 日 × 25 特征 = 45,040,675 个原始数值 |
| 股票-日 | 1,801,627 |
| 训练窗口（20 日上下文 → 未来 5 日，逐日采样） | 425,610 |
| 本模型参数 | **526,115**（2.01 MiB fp32 / 1.00 MiB fp16 / 0.50 MiB int8） |
| 每参数原始数值 | 85.6 |
| 每参数训练窗口 | 1.24 |
| 每轮梯度步 | 182（8 个交易日/步） |

分解：VAE 99,008；DiT 3 个 block 334,947；共享 adaLN 55,872；时间/regime 嵌入 31,872；位置嵌入 4,416。

对照 v2 的 5 条监督路线（3.2 万–9.6 万参数、Rank IC 0.043–0.060），2 MB 把容量放大了 5–16 倍；但本实验里验证集没有变好，和"容量不是瓶颈"的判断一致。若把 2 MB 理解成 200 万参数（fp16 4 MB），数据仍能训（训练损失会继续降），但按本轮证据，样本外 IC 不会因此提升，只会更快过拟合。

## 3. 训练

- 标签：`open[t+6]/open[t+1]-1` 的当日截面排名 `z ∈ [-1,1]`（与 v2 一致）。
- 阶段 1：VAE 重建热身 2 轮，然后联合训练 flow matching（`recon_weight=0.1`）。
- 数据切分：训练 2016–2021（1,455 个信号日）、验证 2022–2023（478）、测试 2024–2026-11-09（683）。
- 优化：AdamW，lr 1e-3，cosine，wd 1e-4，梯度裁剪 1.0，15 轮（约 49 秒）；按验证重建损失取第 8 轮。训练在 lab 的 Slurm GPU 节点上跑（`dreamina.sbatch`，作业 2733，RTX 5090），数据读 `/mnt/storage1/.../Share/gru/data`，结果写 `/mnt/storage1/.../Share/dreamina/`。
- 阶段 2：冻结生成器，用生成出的未来 5 日特征（或对照：最近 5 日上下文特征）训练一个小 probe（LayerNorm → Linear 32 → GELU → Linear 1，Huber）。
- 阶段 3：probe 分数 → v2 的低换手组合（30 只、跌出前 50 才卖、每 5 日最多换 5 只、次日开盘、买 0.10%/卖 0.20%、1% 成交额上限）。

## 4. 结果（测试 2024-01-03 → 2026-11-09，688 个交易日）

**主实验：16 股/patch，2.01 MB，205 个未来 token（`reports/`）**

| Probe | 验证 IC | 测试 IC | 累计收益 | 最大回撤 | Sharpe | 年化费用/净资产 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 生成未来 5 日 + 上下文（Dreamina 路线） | 0.0348 | 0.0423 | +39.01% | -25.22% | 0.66 | 2.59% |
| 最近 5 日上下文（对照） | 0.0439 | 0.0539 | +45.65% | -21.26% | 0.77 | 2.58% |
| v2 GRU+注意力（参考） | — | 0.0636 | +30.33% | -16.09% | 0.70 | 2.47% |
| 真实未来 5 日特征（泄漏上界，仅诊断） | 0.9747 | 0.9697 | +15,601% | -9.83% | 7.01 | 2.56% |

**稳健性：8 股/patch，1.87 MB，410 个未来 token（lab Slurm 作业 2734，`reports_g8/`）**

| Probe | 验证 IC | 测试 IC | 累计收益 | 最大回撤 | Sharpe |
| --- | ---: | ---: | ---: | ---: | ---: |
| 生成未来 5 日 + 上下文 | 0.0423 | 0.0443 | +34.47% | -31.36% | 0.62 |
| 最近 5 日上下文（对照） | 0.0306 | 0.0366 | +44.32% | -21.36% | 0.77 |

> 8 股/patch 变体只重跑了核心的"生成 vs 上下文"对照；"只用生成结果"和"真实未来特征上界"两个诊断只在主实验里测（0.0053 / 0.9697）。

图：[training.png](reports/training.png)（FM/重建损失）、[equity.png](reports/equity.png)（16 股/patch 的三条净值曲线）；8 股/patch 的对应图在 `reports_g8/`。原始分数矩阵在 `reports*/scores_*.npy`，逐日指标在 `reports*/metrics.json`。

**probe 种子噪声**：同一份上下文特征，用 6 个随机种子重训 probe，测试 IC = **0.048 ± 0.008**（范围 0.036–0.057，见 `reports/probe_variance.csv`）。上表里生成 0.0388/0.0470、对照 0.0539/0.0366 都落在这一区间内——所以"生成 vs 不生成"的差异不能按点估计去读。

**怎么读这张表**：

1. **生成 vs 不生成的符号会翻转**：16 股/patch 是 0.0423 < 0.0539，8 股/patch 是 0.0443 > 0.0366。差距都在 ±0.01–0.02，和 probe 种子/回测路径的噪声同量级；因此不能得出"生成式预训练有效"的结论，也不能得出"一定有害"的结论。
2. **只喂生成结果几乎没有信号**（主实验测试 IC 0.0053）。生成模型学到的主要是"未来的平滑条件均值"，对 5 日截面排序不够。
3. **回测收益和 IC 不单调**：两条 2 MB 路线的累计收益都能高于 GRU 参考，但最大回撤更大；回测区间的 2024–2026 已经被看过，不是严格前向证据，不能据此说 2 MB 模型更好。
4. **泄漏上界 IC 0.97**：证明"面板 → 视频 → probe → 组合"的管线和记账不是瓶颈；真正难的是预测未来 5 日截面。
5. 8 股/patch 的 VAE 重建更好（验证 7.76 vs 9.46），生成 IC 也更高（0.0443 vs 0.0366），但回测更差（+34.5% vs +44.3%）；说明"重建更准"不等于"选股更好"。

## 5. 局限

- 测试区间 2024–2026 已经查看过，结果只能作为历史比较，不是严格前向。
- 单随机种子、单数据源（BaoStock 面板）；没有做 purged/embargo 交叉验证。
- VAE 重建误差仍然偏高（验证 MSE 9.5 vs 特征方差 ~1.6），未来 5 日的细节被压缩掉了；这是生成特征偏噪声的直接原因。
- 生成只做了一次采样（固定种子），没有做多样本平均/不确定性估计。
- 回测沿用 v2 的 1M 分数份额口径，不是平台的小资金整手口径；费用是 0.10%/0.20% 的全包近似，未逐项拆佣金/印花税/过户费。
- "Dreamina v4" 按即梦/Dreamina 4.0 = Seedream 4.0 理解；如果指的是另一条视频模型线（如 Seedance），映射关系不变，但 block/VAE 的具体细节需要按对应技术报告替换。

## 6. 复现

```bash
# 依赖
~/miniconda3/bin/python -m venv ~/.venvs/dreamina
~/.venvs/dreamina/bin/python -m pip install torch numpy scipy pandas matplotlib \
  -i https://pypi.tuna.tsinghua.edu.cn/simple

# 主实验：同步到 lab 后用 Slurm 提交（推荐）
rsync -az --exclude 'reports*' --exclude '__pycache__' experiments/ \
  lab:/home/syk/experiments/Share/dreamina/experiments/
rsync -az experiments/dreamina_stock/dreamina.sbatch \
  lab:/home/syk/experiments/Share/dreamina/
ssh lab 'cd /home/syk/experiments/Share/dreamina && sbatch dreamina.sbatch'

# 8 股/patch 变体
ssh lab 'cd /home/syk/experiments/Share/dreamina && CONFIG=config_g8.json OUTDIR=results_g8 sbatch --job-name dreamina-g8 dreamina.sbatch'

# 本地冒烟（不用于正式结果）
~/.venvs/dreamina/bin/python -m experiments.dreamina_stock.train --smoke
```

输入面板默认读 `~/labs/VLA/Share/v2/local_data`（可用 `VLA_PANEL_DIR` 覆盖），回测直接复用 v2 的 `compute.py` 记账函数（代码目录可用 `VLA_CODE_DIR` 覆盖）。
